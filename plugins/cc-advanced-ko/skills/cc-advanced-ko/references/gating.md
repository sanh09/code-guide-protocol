# 수준 확인 절차 (고급)

## 1. 학습 기록 읽기

`~/.claude/cc-tutor-progress.md`가 있는지 확인하고, 있으면 읽는다. 파일 도구를 쓸 수 없는 환경이면 이 단계를 건너뛴다.

- `중급(cc-intermediate-ko): 수료` 또는 `확인 퀴즈 통과` → 4번으로 (바로 시작)
- 그 밖의 경우 → 2번으로 (기록에 있는 개발 경험·기초 수료 정보는 다시 묻지 않는다)

## 2. 학습자에게 묻기

선택형 질문 도구가 있으면 쓰고, 없으면 번호를 붙여 텍스트로 묻는다.

> 고급 과정은 셸 스크립트와 JSON 설정, git을 직접 다루고, 훅처럼 명령을 자동으로 실행하는 기능도 배워요. 시작 전에 확인할게요.
>
> **1. 개발 경험이 있으신가요?** (코드를 직접 작성하고 터미널에서 git을 써 봤다면 "있음")
> ① 있음 ② 없음
>
> **2. 중급 과정(cc-intermediate-ko)을 마치셨나요?**
> ① 마쳤어요 ② 아직이에요
>
> **3. (개발 경험이 없다면) 기초 과정(cc-basics-ko)을 마치셨나요?**
> ① 마쳤어요 ② 아직이에요

판단:

| 개발 경험 | 기초 | 중급 | 다음 행동 |
|---|---|---|---|
| 상관없음 | 상관없음 | 수료 (기록 있음) | 4번 시작 |
| 있음 | 상관없음 | 마쳤어요 (기록 없음) 또는 아직 | 3번 중급 확인 퀴즈 |
| 없음 | 마쳤어요 | 마쳤어요 (기록 없음) | 3번 중급 확인 퀴즈 |
| 없음 | 마쳤어요 | 아직 | 5번: 중급 과정으로 안내 |
| 없음 | 아직 | 상관없음 | 5번: 기초 과정으로 안내 |

개발 경험이 있으면 중급을 정식으로 마치지 않았어도, 확인 퀴즈를 통과하면 고급으로 갈 수 있다. 개발 경험이 없으면 기초부터 순서대로 가야 한다.

## 3. 중급 확인 퀴즈 (5문제, 4문제 이상 통과)

정답은 학습자가 답한 뒤에 공개한다.

1. allow에 `Bash(aws s3 ls)`, deny에 `Bash(aws *)`가 있다. `aws s3 ls` 실행은? ① 허용 ② 거부 ③ 물어본다 ④ 오류 → ② (deny → ask → allow 순서)
2. `git diff`로 시작하는 명령만 허용하고 `git diff-index`는 맞지 않게 하는 규칙은? ① `Bash(git diff*)` ② `Bash(git diff *)` ③ `Bash(git*)` ④ `Bash(*)` → ②
3. 사용자가 `/deploy`로 부를 때만 실행되고 Claude가 알아서 실행하지 않는 스킬을 만들려면 머리말에? ① `user-invocable: false` ② `disable-model-invocation: true` ③ `allowed-tools: none` ④ `model: haiku` → ②
4. `claude -p` 결과를 스크립트에서 파싱하려면? ① `--output-format json` ② `--verbose` ③ `--continue` ④ `--bare`만 쓰기 → ①
5. Claude가 Bash `rm`으로 지운 파일을 되돌리는 가장 믿을 만한 방법은? ① `/rewind` ② `/compact` ③ git으로 미리 커밋해 둔 상태에서 복구 ④ `/clear` → ③ (체크포인트는 Bash 변경을 추적하지 않는다)

- **4문제 이상**: 통과. 동의를 받아 기록에 `중급(cc-intermediate-ko): 확인 퀴즈 통과 (YYYY-MM-DD, N/5)`를 남기고 시작한다.
- **3문제 이하**: 틀린 주제를 짚고 5번으로 간다(중급 과정, 필요하면 해당 레슨만 복습).

## 4. 시작

"확인됐어요. 고급 과정을 시작할게요"라고 한 줄로 말하고 레슨 목록을 보여 준다. 그다음 학습자의 목표를 묻는다.

## 5. 이전 과정으로 안내

고급 레슨은 진행하지 않는다. 다음을 친절하게 전한다.

- 이유 한두 문장 (예: "훅과 자동화는 명령을 자동으로 실행해서, 권한 규칙과 `-p`를 먼저 익혀 두어야 안전하게 쓸 수 있어요")
- 안내할 과정과 시작 방법:
  - 기초: "Claude Code 처음부터 알려주세요" 또는 `/cc-basics-ko:cc-basics-ko`
  - 중급: "Claude Code 중급 시작할래요" 또는 `/cc-intermediate-ko:cc-intermediate-ko`
  - 설치하지 않았다면:
    ```
    /plugin marketplace add sanh09/claude-guide
    /plugin install cc-basics-ko@sanh09-skills
    /plugin install cc-intermediate-ko@sanh09-skills
    ```
- 퀴즈를 아깝게 통과하지 못했다면(3/5) 해당 중급 레슨만 복습하고 다시 확인 퀴즈를 볼 수 있다고 알려 준다.

## 학습 기록 형식

`~/.claude/cc-tutor-progress.md`를 기초·중급·고급 스킬이 같이 쓴다. 파일이 없으면 만들고, 있으면 해당 줄만 고친다. **동의를 받고** 쓴다.

```markdown
# Claude Code 학습 기록
- 개발 경험: 있음
- 기초(cc-basics-ko): 건너뜀 (개발 경험 있음)
- 중급(cc-intermediate-ko): 확인 퀴즈 통과 (2026-11-25, 5/5)
- 고급(cc-advanced-ko): 진행 중 (레슨 2까지)
```

고급 줄에 쓰는 값: `미시작` / `진행 중 (레슨 N까지)` / `수료 (YYYY-MM-DD, 종합 퀴즈 N/5)`
