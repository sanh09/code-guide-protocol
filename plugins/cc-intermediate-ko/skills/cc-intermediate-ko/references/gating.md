# 수준 확인 절차 (중급)

## 1. 학습 기록 읽기

`~/.claude/cc-tutor-progress.md`가 있는지 확인하고, 있으면 읽는다. 파일 도구를 쓸 수 없는 환경이면 이 단계를 건너뛴다.

- `개발 경험: 있음` → 3번으로 (바로 시작)
- `기초(cc-basics-ko): 수료` → 3번으로 (바로 시작)
- 그 밖의 경우 → 2번으로

## 2. 학습자에게 묻기

선택형 질문 도구가 있으면 그것을 쓰고, 없으면 번호를 붙여 텍스트로 묻는다. 두 질문을 한 번에 묻는다.

> 중급 과정은 터미널과 Claude Code 기초에 익숙하다는 전제로 진행해요. 시작 전에 두 가지만 확인할게요.
>
> **1. 개발 경험이 있으신가요?** (코드를 직접 작성해 봤거나, 터미널에서 git 같은 명령을 써 본 적이 있으면 "있음")
> ① 있음 ② 없음
>
> **2. (개발 경험이 없다면) 기초 과정(cc-basics-ko)을 마치셨나요?**
> ① 마쳤어요 ② 아직이에요

판단:

| 개발 경험 | 기초 수료 | 다음 행동 |
|---|---|---|
| 있음 | 상관없음 | 바로 시작. 기록에 `개발 경험: 있음` 저장(동의 시) |
| 없음 | 마쳤어요 (기록 있음) | 바로 시작 |
| 없음 | 마쳤어요 (기록 없음) | 4번 기초 확인 퀴즈 |
| 없음 | 아직이에요 | 5번 기초 과정으로 안내 |

학습자가 개발 경험을 "조금", "HTML만 해 봤어요"처럼 애매하게 답하면, 터미널에서 `cd`, `ls`, `git` 같은 명령을 써 봤는지 한 번만 더 묻는다. 써 봤다면 '있음'으로 본다. 아니면 '없음'으로 본다.

## 3. 시작

"확인됐어요. 중급 과정을 시작할게요"라고 한 줄로 말하고 레슨 목록을 보여 준다.

## 4. 기초 확인 퀴즈 (5문제, 4문제 이상 통과)

기록이 없는 "수료했어요"를 확인하는 용도다. 아래 문제를 내고, 정답은 학습자가 답한 뒤에 공개한다.

1. 같은 작업을 계속하는데 대화가 너무 길어져서 흐름은 유지한 채 공간을 확보하려면? ① `/clear` ② `/compact` ③ `/exit` ④ `/init` → ②
2. Claude를 거치지 않고 터미널 명령 `ls`를 바로 실행하는 입력은? ① `/ls` ② `@ls` ③ `! ls` ④ `# ls` → ③
3. 모든 프로젝트에 적용할 나만의 지침을 쓰는 곳은? ① `./CLAUDE.md` ② `~/.claude/CLAUDE.md` ③ `./CLAUDE.local.md` ④ `.claude/settings.json` → ②
4. 팀원과 공유하지 않고 이 프로젝트에서 나만 쓸 설정 파일은? ① `.claude/settings.json` ② `~/.claude/settings.json` ③ `.claude/settings.local.json` ④ `CLAUDE.md` → ③
5. 큰 작업 전에 Claude가 파일을 바꾸지 않고 계획만 보여 주게 하려면? ① plan 모드 ② acceptEdits 모드 ③ `/compact` ④ `/resume` → ①

- **4문제 이상 정답**: 통과. 동의를 받아 기록에 `기초(cc-basics-ko): 수료 (확인 퀴즈 N/5)`를 남기고 시작한다.
- **3문제 이하**: 틀린 문제의 주제를 짚어 주고 5번으로 간다. "이 부분만 기초 과정에서 복습하고 오시면 돼요"처럼 부담을 줄여 말한다.

## 5. 기초 과정으로 안내

중급 레슨은 진행하지 않는다. 다음 내용을 친절하게 전한다.

- 왜 기초가 먼저인지 한두 문장 (예: "중급은 터미널 명령과 설정 파일을 직접 다뤄서, 기초가 없으면 실습에서 막히기 쉬워요")
- 기초 과정 시작 방법:
  - 이미 설치했다면 "Claude Code 처음부터 알려주세요"라고 말하거나 `/cc-basics-ko:cc-basics-ko` 입력
  - 설치하지 않았다면:
    ```
    /plugin marketplace add sanh09/code-guide-protocol
    /plugin install cc-basics-ko@sanh09-skills
    ```
- "기초를 마치고 다시 오시면 바로 중급을 시작할게요"로 마무리

## 학습 기록 형식

`~/.claude/cc-tutor-progress.md` 하나를 기초·중급·고급 스킬이 같이 쓴다. 파일이 없으면 새로 만들고, 있으면 해당 줄만 고친다. 학습자 컴퓨터에 쓰는 일이므로 **동의를 받고** 쓴다.

```markdown
# Claude Code 학습 기록
- 개발 경험: 있음
- 기초(cc-basics-ko): 건너뜀 (개발 경험 있음)
- 중급(cc-intermediate-ko): 진행 중 (레슨 3까지)
- 고급(cc-advanced-ko): 미시작
```

중급 줄에 쓰는 값: `미시작` / `진행 중 (레슨 N까지)` / `수료 (YYYY-MM-DD, 종합 퀴즈 N/5)` / `확인 퀴즈 통과 (YYYY-MM-DD, N/5)`
